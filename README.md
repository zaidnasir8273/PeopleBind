# PeopleBind

A modern HR &amp; Payroll SaaS for Pakistani businesses. Built by UpScale.

## Stack

- React + Vite (frontend)
- Supabase — Postgres, RLS, Auth, Storage (backend)
- Netlify (hosting)

## Local development

```bash
npm install
npm run dev
```

## Deployment

Connected to Netlify via this repo. Every push to `main` deploys
automatically. Build command and publish directory are set in
`netlify.toml`.

## Status

Early development. Backend schema (Foundation, People, Attendance,
Leave) is in place on Supabase. Frontend is currently a placeholder —
this README will grow as real screens get built.
